# разминка для глаз — план реализации

> для исполнителя: обязательный навык — `superpowers:executing-plans` для самостоятельного исполнения либо `superpowers:subagent-driven-development`, если пользователь выберет делегирование. выполнять задачи последовательно через red → green; отмечать завершённые шаги.

**цель:** добавить собственную разминку с 11 упражнениями, статистикой и общим напоминанием во все страницы существующего дашборда.

**архитектура:** чистые umd-модули определяют каталог, программу, траектории, часы и статистику; контроллеры страницы и напоминания принимают эффекты через адаптеры. пользовательские данные сохраняются существующим каналом аккаунта, служебная координация остаётся только в браузере. на остальных страницах нет фоновой анимации тренажёра.

**стек:** vanilla javascript, html/css, `node:test`, браузерные web locks / indexeddb, существующие gamification и supabase sync; без новых зависимостей и схем базы.

**спецификация:** [утверждённый дизайн](../specs/2026-10-24-eye-breaks-design.md). награды привычек имеют [собственный независимый план](2026-10-24-habit-rewards.md) и не являются зависимостью этого плана.

## общие ограничения

- время всего занятия: только `30`, `60`, `120`, `180` секунд; короткий доступен во всех длительностях, полный — только `120`/`180`.
- все 11 идентификаторов и минимумы из спецификации: обычные этапы — `8` секунд, `near-far` — `12`, `distance` — `20`.
- скорость скачков: `1800`/`1200`/`800` миллисекунд; скорость не меняет общий бюджет.
- календарь: `Asia/Yekaterinburg`; пауза, фон, отмена и пропуск этапа не создают завершённое занятие.
- напоминание: `20` минут календарного времени при открытом дашборде, отложить — `5` минут, перерыв — `20` секунд; не более одного показа за интервал в одном браузере.
- без камеры, ии, медицинских обещаний, новых серверов, таблиц, service worker, системных push-разрешений и изменений школьного адаптера.
- новая страница не добавляется в нижнюю навигацию; исходники и медиа eyesly не копируются.
- коммиты и github-текст — по-русски, с маленькой буквы, без соавторства; merge запрещён без отдельного решения пользователя.

## фокус проверки

1. storage запрещён, переполнен или содержит повреждённые данные: интерфейс работает без выдуманного подтверждения сохранения — задачи 3 и 6.
2. вкладка скрылась, устройство уснуло или аккаунт сменился: нет фонового прогресса и применения чужого активного занятия — задачи 2–4.
3. два окна одновременно требуют напоминание или продолжение: показывается один владелец, недоступный резервный механизм не превращается в небезопасный localStorage-mutex — задачи 5 и 7.
4. история больше серверной страницы, одна страница запроса упала или устарела: частичная выборка не применяется как полная — задача 4.
5. браузер отказал в звуке, вибрации или fullscreen; включено уменьшение движения: управление не застревает, выбранное упражнение не подменяется — задачи 6–8.

## файлы и границы

- `eyes-data.js`: каталог, нормализация настроек, валидация завершённых записей и чистая сводка статистики; глобально `EyesData`.
- `eyes-core.js`: построение программы, траектории и инструкции этапов; глобально `EyesCore`, только на странице разминки.
- `eyes-session.js`: чистый автомат таймера; глобально `EyesSession`, без dom и storage.
- `eyes-store.js`: адаптер настроек, неизменяемых завершений, сброса и подписок; глобально `EyesStore`.
- `eyes-coordination.js`: локальная атомарная координация, владение активным занятием и обмен сообщениями вкладок; глобально `EyesCoordination`.
- `eyes-reminder-core.js`: чистый автомат срока и отложенного напоминания; глобально `EyesReminderCore`.
- `eyes-reminder.js` / `eyes-reminder.css`: лёгкая общая точка входа, ленивый запуск включённого напоминания, уведомление и таймер вдаль.
- `eyes.html` / `eyes.css` / `eyes.js`: страница, редактор, плеер и доступное управление.
- `index.html`: переходник под помодорками; остальные пользовательские html — только подключение общего напоминания и cache version.
- `supabase-sync.js`: постраничная загрузка и исключение служебных ключей; `profile.html`: backup разрешённых данных.
- `test/eyes-*.test.cjs`, `test/supabase-sync.test.cjs`: новые тесты и расширение существующих mock-контрактов.

## общий договор данных

- `Settings = {version:1, mode, durationSeconds, exerciseIds, speed, dotSize, dotColor, showPath, soundEnabled, vibrationEnabled, fullscreenEnabled, reminderEnabled}`.
- `mode`: `short|full|custom|single`; default `short`. время default `60`; `exerciseIds` — уникальные id в порядке каталога, default `horizontal/vertical/blinking`; `speed` — `slow|normal|fast`, default `normal` или `slow` при первоначальном reduced motion. сохранённый явный выбор не переписывается медиазапросом.
- `dotSize`: `small|medium|large`, default `medium`; `dotColor`: `amber|mint|white|pink`, default `amber`; `showPath:true`, `soundEnabled:true`, `vibrationEnabled:false`, `fullscreenEnabled:false`, `reminderEnabled:false`. небезопасные css-строки и неизвестные значения нормализуются, не передаются в dom как стили.
- завершённая запись: `{version:1,id,epoch,completedAt,durationSeconds,mode,exerciseIds}`; uuid `id`, iso `completedAt`, строка поколения, уникальный разрешённый каталог. `mode:'reminder'` разрешает только `durationSeconds:20` и `exerciseIds:['distance']`; остальные modes требуют одну из четырёх выбранных длительностей. нет user metadata, jwt или секретов.
- активный снимок дополнительно хранит `owner`, frozen plan, phase, played/cursor время, skipped и id; только служебный storage. `epoch` по умолчанию `initial`, после reset — новый uuid. завершение старого поколения после reset не возвращает статистику.
- `near-far`, `blinking`, `rest` дают инструкции, а не фиктивный eye-tracking score. настройки зафиксированного занятия не зависят от следующих изменений `Settings`.

### задача 5: координация вкладок и чистое напоминание

**файлы:** создать `eyes-coordination.js`, `eyes-reminder-core.js`, `test/eyes-coordination.test.cjs`, `test/eyes-reminder-core.test.cjs`.

**интерфейсы:**

- `EyesCoordination.create({locks, indexedDB, storage, channelFactory, now, uuid, tabId}) -> {withLock, claimSession, renewSession, releaseSession, subscribe, close}`.
- `withLock(name, work) -> Promise<Result>` — web locks при поддержке; резерв — атомарная indexeddb-транзакция с token/lease, не последовательный select/set в localStorage. нет доступного атомарного механизма → понятная ошибка, не разрешение двум владельцам.
- активное занятие: lease `15s`, продление раз в `5s`; потеря lease ставит занятие на паузу и требует повторного захвата перед продолжением. token не снимает чужое владение.
- `EyesReminderCore.reduce(state, event) -> {state, effects}`; state включает `enabled`, `dueAt`, `cycleId`, `claimedCycle`, `distanceSession`, `owner`. события: enable/disable, open/close, visibility, tick, later, startDistance, completeDistance, completeExercise, ownerChanged.
- эффекты — данные `show/hide/startDistance/resetDeadline`, не dom; длительности `1200000`, `300000`, `20000ms`.
- события tick передают отдельно wall-clock `nowMs` для срока напоминания и монотонное `monoMs` для запущенного перерыва. 20-секундный перерыв останавливается при hidden, поддерживает явные pause/resume/cancel и создаёт record только после 20 активных секунд без отмены.
