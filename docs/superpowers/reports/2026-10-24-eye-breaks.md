# разминка для глаз и награды привычек — итог реализации

## результат

- на главной под помодорками появился переходник на `eyes.html`; новой вкладки нижней навигации нет.
- 11 собственных упражнений: горизонталь, вертикаль, две диагонали, круг, восьмёрка, прыжки взгляда, близко/далеко, взгляд вдаль, моргание, отдых с закрытыми глазами.
- общая длительность 30 / 60 / 120 / 180 секунд; короткий, полный и свой комплексы, одиночные упражнения. полный комплекс доступен на 2 и 3 минуты.
- три темпа, размер/цвет точки, траектория, звук, вибрация и fullscreen; пауза, пропуск, выход и восстановление с паузы.
- статистика и настройки используют существующий канал аккаунта. скрытая вкладка, потеря lease и разрыв исполнения дольше 5 секунд останавливают прогресс; сон не считается практикой.
- добровольное напоминание 20–20–20 работает на всех страницах; «позже» откладывает на 5 минут; навигация сохраняет срок. без service worker и системных push.
- полезная привычка даёт 2 монеты, половина — 1; снятие/изменение корректирует реально выплаченную сумму. старые отметки не оплачиваются при загрузке. `spent` не увеличивается от возврата награды.
- локальные habit-команды координируются web locks / indexeddb; owner-scoped journal восстанавливает принятую операцию, ledger хранит идентичность принятых команд. повтор старой команды после последующих действий тоже идемпотентен.
- история профиля показывает подписанные корректировки безопасно. существующие штрафы, покупки и две версии gamification не объединялись.

## решения реализации и их стоимость

1. русский task brief прочитан напрямую: skill-helper распознаёт только английский заголовок. стоимость — ручное извлечение brief, поведение продукта не меняется.
2. общий `browser-lock.js` вместо двух копий. стоимость — маленькая общая зависимость; eye/reward state не объединены.
3. финальная приёмка после обеих подсистем, один whole-branch review. стоимость — результат обеих работ передаётся вместе.
4. journal разбит по владельцам. стоимость — по одному приватному ключу на незавершённого владельца вместо риска затереть чужую операцию.
5. тонкий `habit-rewards-ui.js` для pending/error tests. стоимость — один дополнительный локальный script.
6. 200% проверены через эквивалентный layout viewport. стоимость — не автоматизирован нативный toolbar zoom конкретного браузера.
7. completion cue повышен до important и исправлен. стоимость — дополнительный мягкий сигнал, только при включённом сопровождении.
8. межустройственная денежная транзакция не добавлялась. стоимость — существующие конкурентные записи с разных устройств могут конфликтовать. lock относится к habit-командам, не ко всем старым денежным операциям приложения.
9. повторный аудит неизменённых migrations/rls/школьных команд не проводился. стоимость — их старые независимые проблемы не исключены этой работой.
10. медицинская эффективность и выполнение человеком не проверяются. стоимость — статистика означает завершённый таймер, не доказанное упражнение или лечение.
11. production и реальный аккаунт не использовались для приёмки. стоимость — реальная cloud-синхронизация и опубликованный сайт требуют отдельной проверки после merge/deploy.
12. визуальная приёмка отделена от code review. стоимость — screenshots доказывают изолированный browser run, не production.
13. один независимый reviewer без платного внешнего review. стоимость — исправления автора подтверждены тестами, не второй независимой оценкой.

отложенных minor нет. автоматического merge нет.

## данные и ограничения

новые пользовательские ключи: `eye_break_settings_v1`, `eye_break_stats_epoch_v1`, immutable `eye_break_session_v1:<uuid>`. служебные `_eye_break_` и `_habit_reward_` исключены из cloud/backup. ledger и идентичности денежных команд остаются в `coins_v1`; их объём растёт с явными операциями, без автоматического исторического backfill.

исправленная пагинация сначала собирает все страницы и только затем применяет актуальный снимок; ошибка/смена аккаунта не превращает частичный ответ в полную историю. новых таблиц, секретов во frontend, ai-функций, камер и платных api не добавлено. звук/fullscreen/вибрация зависят от разрешений и возможностей браузера; отказ не блокирует упражнения.
